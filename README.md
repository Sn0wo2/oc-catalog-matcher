# Installation

Find your OpenCode2 config at ~/.config/opencode.jsonc

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  // ...
  "plugins": [
    // ...
    "github:Sn0wo2/oc-catalog-matcher"
  ]
}
```
